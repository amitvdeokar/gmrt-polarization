# GMRT Polarization Pipeline
`gmrt-polarization` is a specialized data reduction tool designed to process raw data collected by the GMRT telescope. The
pipeline transforms raw data, which is stored in computer disk files through the Data Acquisition System (DAS), into complete Stokes folded polarization profiles. The pipeline is developed under National Center Radio Astrophysics (NCRA, Pune) [SPOTLIGHT](https://spotlight.ncra.tifr.res.in/) initiative to compute polarization profile for Fast Radio Bursts (FRBs) but can also be used for Pulsar and Long Period Transients (LPTs). FRB and LPT polarization calibration is performed using a known pulsar observed in the same epoch as a reference calibrator.

The pipeline is written purely in Python (Version 3). Users can interact with the pipeline through command line operations, making it a flexible and efficient solution for managing and analyzing polarization data. The design and implementation of this pipeline reflect the specific needs of radio astrophysics research, ensuring that it can handle the complexities of the
data generated by the GMRT telescope.
